# Security Policy

## Educational Use Only

This repository contains Python scripts designed to demonstrate the mechanics of hybrid cryptography (AES-256-GCM + RSA-2048). **This code is strictly for educational and academic research purposes.**

It is designed to be run exclusively in isolated, offline Virtual Machines (e.g., VMware or VirtualBox). 

## Prohibited Use

The author strictly prohibits the use of this code for malicious purposes, unauthorized access, or real-world extortion. 
- The GUI provided is a simulated "impact" screen for research purposes only.
- No actual payment mechanisms (Bitcoin wallets) are functional or real.
- No operational malware executables (`.exe`) are distributed in this repository.

## Reporting a Vulnerability

If you find a flaw in the cryptographic implementation (e.g., nonce reuse, padding oracle) or a bug in the Python scripts, please open an Issue or submit a Pull Request so we can improve the educational quality of the lab.
